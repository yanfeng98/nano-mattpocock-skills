# 中文翻译约定（i18n）

`skills/**` 的散文用简体中文书写，结构与机器标识保留英文。这份文件是这套约定的唯一权威：新翻译、改译、新增技能都照它来。

## 为什么

技能不是文档，是给 agent 读的指令，而且技能之间靠字符串互相识别：Skill 工具的参数、分诊标签、写进目标仓库的标题、被别的技能读回的节名。散文可以换成中文，这些字符串一换，一条指令就会静默指向空气。所以约定只有一条分界线：**能读的译，能跑的留**。

## 语言约定

**保留英文（字节不变）**

- frontmatter 里除 `description` 之外的一切：`name`、`disable-model-invocation`、`argument-hint` 的键名、`metadata.*`
- 一切标识符：技能名、斜杠命令、Skill 工具的参数、标签与枚举值、文件名与路径、CLI flag、环境变量、代码标识符、URL
- 反引号内的一切；围栏内的代码（含代码里的注释）
- 写进目标仓库或跟踪器的结构：标题、字段名、`- [ ]`、`Status:` 一类标记、`_Avoid_`、`{{占位符}}`、`<占位符>`
- 锚点目标标题，以及被别的文件点名引用的标题

**译成中文**

- 一切指令、定义、解释、清单项、表格里的人读文字
- 模板围栏内的占位说明文（例如 `<what reaching the end of this map looks like: …>`），标题与字段名除外
- 示例正文（示例工单、示例简报、示例术语表），字段名除外

**中英并列**

- `description`：中文句子，保留英文触发词（`grill`、`red-green-refactor`、`review since X`），让中文说法和英文短语都能命中
- 承重词汇首次出现处写 `中文（English）`，例如 `接缝（seam）`、`曳光弹（tracer bullet）`，其后只用中文
- 术语锁定行写成 `_Avoid_: unit, component, service（单元、组件、服务）`，英文原词不丢，中文禁词交给术语表的禁译词列在全仓执行

**行映射**

一个英文行对应一个中文行。不合并、不折行、不重排、不删空行。中英逐行可以对照，是评审和校验的基础；例外要在提交信息里说明。

**标点**

全角标点，不使用任何破折号（`—`、`――`、`——`、`–`）。英文原文里表示区间的连字符保持连字符。

## 维护

- 新术语：在 `glossary.tsv` 加一行，再重新生成这份文件，不要手改表格。
- 禁译词列是硬约束：全仓不得出现，出现即判失败。这是防术语漂移的主要手段。
- 改译一个既有术语等于全仓回改，改之前先确认值不值。
- `agents/openai.yaml` 的 `interface.*`、`scripts/` 下的脚本、`docs/` 页面、`CHANGELOG.md` 不在本约定范围内，仍为英文。

# 杂项

留着但很少用的工具。这里的东西都不推广：`scripts/link-skills.sh` 会跳过这个桶，顶层 README 也一样。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：配置 Claude Code hook，在危险 git 命令（push、reset --hard、clean 等）执行之前把它们拦下。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把测试文件从 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建练习目录结构，含章节、题目、答案与讲解。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置 Husky pre-commit hook，接入 lint-staged、Prettier、类型检查与测试。

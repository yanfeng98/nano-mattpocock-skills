# Triage Labels

这些技能说的都是五个规范分诊角色。这份文件把这些角色映射到这个仓库的问题跟踪器里实际使用的标签字符串。

| mattpocock/skills 里的标签 | 本仓库跟踪器里的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                 |
| `needs-info`               | `needs-info`         | 在等报告人补充信息                       |
| `ready-for-agent`          | `ready-for-agent`    | 已完整说明，可以交给 AFK 的 agent        |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现                             |
| `wontfix`                  | `wontfix`            | 不会处理                                 |

当某个技能提到一个角色时（例如 "apply the AFK-ready triage label"），就用这张表里对应的标签字符串。

把右边那一列改成你实际使用的词汇。
